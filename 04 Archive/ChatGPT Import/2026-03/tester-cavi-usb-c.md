## 1) Tester USB-C “base” (potenza e ricarica)

image_group{"aspect_ratio":"1:1","query":["USB-C power meter tester display PD watt meter","USB C tester voltage current meter OLED","USB-C inline tester watt meter charging display","USB C power analyzer small device"],"num_per_query":1}

### Cosa fanno:
- Volt (V)
- Ampere (A)
- Watt (W)
- Protocollo di ricarica (PD, QC, ecc.)

### Cosa NON fanno:
- NON ti dicono:
- velocità dati (USB 2.0 / 3.x / 4)
- supporto video (DisplayPort Alt Mode)
- se è Thunderbolt
- qualità reale del cavo

👉 In pratica: utili per capire **se un cavo carica bene**, inutili per capire **che cavo è davvero**.

---

## 2) Tester USB-C avanzati (analisi completa del cavo)

image_group{"aspect_ratio":"1:1","query":["USB C cable tester Power-Z KM003C display tester","FNIRSI USB tester advanced USB C analyzer screen","USB-C cable analyzer Thunderbolt tester PowerZ KM002C","USB C tester E-marker reader"],"num_per_query":1}

Questi sono quelli che cerchi davvero.

### Cosa fanno:
- Leggono il **chip E-Marker** del cavo
- Ti dicono:
- Potenza massima (60W / 100W / 240W)
- Standard USB (2.0 / 3.2 / USB4)
- Supporto Thunderbolt
- Supporto video (DP Alt Mode)
- Capacità reali vs dichiarate

👉 In sostanza: **identificano il cavo**, non solo la corrente.

## Nota importante (che molti ignorano)

- Il tester funziona bene **solo se il cavo ha E-Marker**
(tipicamente:
- 100W+
- USB 3.x / 4
- Thunderbolt)

- I cavi economici (tipo USB 2.0 60W):
→ non hanno chip → **non puoi identificarli davvero**
