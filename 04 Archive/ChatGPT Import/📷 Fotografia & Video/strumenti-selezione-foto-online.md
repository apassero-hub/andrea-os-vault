Perfetto! Ti preparo uno **script Bash** che, dato il file `.txt` generato dal tool (dove ogni riga contiene un nome di file), applica un **colore specifico (tag)** ai file corrispondenti all'interno di una cartella, **compatibile con Photo Mechanic**.

---

### 🎯 Obiettivo:
Applicare un **color tag** (es. rosso, blu, verde…) ai file selezionati, in modo che vengano filtrabili in Photo Mechanic.

> 🟡 **Attenzione:** Photo Mechanic salva i metadati IPTC direttamente nei file (o sidecar). Lo script userà `exiftool` per scrivere il campo `Label`, riconosciuto da Photo Mechanic.

---

## 🧰 **Requisiti:**
- macOS o Linux
- `exiftool` installato → se non l'hai: `brew install exiftool`
- Una cartella con i file selezionati (es. `gallery-final/`)
- Il file `.txt` generato dal tuo proofing tool (es. `proofing_output/galleryA.txt`)

---

## 📜 Script Bash — `apply_color_tag.sh`

```bash
#!/bin/bash

# === CONFIG ===
PROOF_FILE="proofing_output/galleryA.txt" # file con nomi selezionati
IMAGE_DIR="galleries/galleryA" # cartella contenente le immagini
COLOR_LABEL="Red" # colore da assegnare (Red, Blue, Green, Yellow...)

# === PROCESS ===
echo "Applico il tag colore '$COLOR_LABEL' ai file elencati in $PROOF_FILE..."

while IFS= read -r line; do
FILE=$(echo "$line" | cut -f1) # solo il nome file
TARGET="$IMAGE_DIR/$FILE"

if [[ -f "$TARGET" ]]; then
exiftool -overwrite_original -Label="$COLOR_LABEL" "$TARGET"
echo "✔️ Tag applicato a $FILE"
else
echo "⚠️ File non trovato: $FILE"
fi
done < "$PROOF_FILE"

echo "✅ Completato. Puoi ora filtrare per colore in Photo Mechanic!"
```

---

### ✅ Esempi di `Label` compatibili con Photo Mechanic:
| Colore | Label da usare |
|------------|------------------------|
| Rosso | `Red` |
| Giallo | `Yellow` |
| Verde | `Green` |
| Blu | `Blue` |
| Viola | `Purple` |
| Nessun tag | `None` (o campo vuoto) |

---

### 📂 File `.txt` accettato (esempio):
```
IMG_0001.jpg 5
IMG_0007.jpg 5
IMG_0010.jpg 5
```

💡 Lo script prende solo la prima colonna (`IMG_0001.jpg`) per applicare il tag.
