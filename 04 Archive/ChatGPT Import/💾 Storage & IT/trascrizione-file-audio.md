# SOLUZIONE DIRETTA

### **A. Converti il file in.m4a e ricaricalo**
È il metodo che risolve più spesso:

1. Apri il file con QuickTime.
2. Vai su **File > Esporta come > Solo audio**.
3. Salva il file.m4a.
4. Ricaricalo nella chat usando:
**+ → Carica file → seleziona il.m4a**

Se funziona, lo vedrai in chat come una “scheda”/anteprima.

---

### **B. Rinomina il file con un nome semplice**
Esempio:
**intervista.m4a**
Evita spazi, accenti, caratteri strani.

---

### **C. Se il file è molto grande, taglialo in due**
È raro, ma può essere il motivo. Puoi usare QuickTime:
**Modifica → Dividi clip → Esporta prima metà → Esporta seconda metà.**

Io poi trascrivo tutto e lo ricompongo.
